Algorithm Visualizer Desktop Application

A comprehensive C# Windows Forms application designed to visualize complex algorithms in real-time. This project was developed as part of the academic requirements for the University of Kelaniya.

Features

1. Sorting Visualizer
- Visualizes various sorting algorithms including **Bubble Sort**, **Selection Sort**, and **Insertion Sort**.
- Configurable array size and animation speed.
- Dynamic bar chart rendering.

2. Pathfinding Visualizer
- Implements the **Dijkstra Algorithm** to find the shortest path on a 2D grid.
- Interactive grid for drawing walls, start points, and end points.
- Real-time visualization of the search expansion (visited nodes) and final path.

Technical Stack
- Language : C#
- Framework : .NET (WinForms)
- Environment : Visual Studio 2022
